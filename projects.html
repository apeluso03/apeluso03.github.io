LoL Survival Tracker

A web app my friends and I use to run a League of Legends challenge. Players spin for champions from a shared pool, losses lead to eliminations, and win streaks earn revive tokens.

  • Frontend built with React, TypeScript, TanStack Query, and Tailwind. Includes spin wheels, a champion pool, a shop, leaderboards, and achievements, and works on mobile.
  • FastAPI backend with a background job that pulls finished matches from the Riot API, checks them against the challenge rules, and records the results. Matches that fail a check are flagged for manual review.
  • Account system with hashed passwords, session cookies, invite links, and lockout after too many failed logins.
  • GitHub Actions CI runs 120+ backend and frontend tests (pytest, Vitest), a production build, and Alembic migration checks.

Fantasy Football AI Agent

An AI agent for my 12-team fantasy football keeper league. It answers keeper, trade, and draft questions using live data from Sleeper and scraped player rankings.

  • Wrote the tool-calling loop myself using the OpenAI Responses API. The model can choose from 9 tools, and every call is logged.
  • Keeper costs, trade values, and power rankings are calculated in regular Python code, not by the LLM. The model decides which tools to use and explains the results. This logic is covered by 84 unit tests.
  • Built a rankings scraper and name matching that automatically matches about 98.6% of players.
  • Packaged two Windows desktop apps: a developer version that shows the raw tool calls, and a user version with a setup wizard that works with any Sleeper league.

FileFlow

A REST API for processing CSV files in the background. You upload a file, get a job ID back, and check the job until the results are ready.

  • Runs on Docker Compose: FastAPI, a Celery worker, Redis, PostgreSQL, and MinIO for S3-compatible file storage. One command starts everything.
  • API key authentication, where each key can only see its own jobs. Results include row counts, column types, null counts, and basic statistics.
  • Files can be stored on local disk or S3, set by an environment variable.
  • 11 integration tests with no mocks, running in CI.

Hydrogen Workforce Scraper · EPRI

My senior design project, built with a team for the Electric Power Research Institute (EPRI). We built a pipeline that finds hydrogen energy courses offered at universities across the U.S.

  • Built the ETL pipeline in Python with Scrapy and Playwright to scrape, filter, and score course data.
  • Collected course catalogs from 50+ universities, covering 92% of HTML-based catalogs.
  • Built a keyword-scoring system to find gaps in hydrogen energy coursework. EPRI used the reports to help make curriculum decisions.
  • Also worked on PDF parsing, handling JavaScript-heavy pages, and Makefile commands for running the pipeline.
